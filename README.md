# Next-flow

A web application for creating and managing AI workflows.

---

## Tech Stack

- `Next.js 16` for the frontend framework
- `TypeScript` for type safety
- `Tailwind CSS` for styling
- `Shadcn UI` for components
- `Prisma` for database management
- `Clerk` for authentication and user management
- `Neon` for database hosting
- `Trigger.dev` for workflow automation
- `Transloadit` for file uploads
- `Gemini` for AI integration
- `React Flow Renderer` for visualizing workflows
- `Zod` for form validation
- `Zustand` for state management
- `FFmpeg` via `Transloadit` for image and audio processing
